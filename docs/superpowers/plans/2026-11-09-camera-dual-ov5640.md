# Dual OV5640 C capture implementation plan

Goal: Run board DVP and MIPI OV5640 capture concurrently without HDMI.
Constraints: Keep existing APIs, reuse dynamic SDRAM allocation and XCLK, no compilation or tests, do not change generated static VIN buffers.
Approach: Hold MIPI in reset, initialize DVP at 0x3C and remap SCCB to 0x3D with readback, then initialize MIPI at 0x3C. Each Camera retains its address. Three dynamic frames per path. Application serializes control operations; DMA paths operate independently.
